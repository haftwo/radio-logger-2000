Running Whisper on Unraid

  1. Speaches (formerly faster-whisper-server) is the best fit: GPU support, word timings and an OpenAI-compatible API on port 8000. Pick OpenAI-compatible.
  2. whisper-asr-webservice (Community Apps: "openai-whisper-asr-webservice") listens on port 9000. Pick whisper-asr-webservice.
  3. Already running faster-whisper for Home Assistant? It speaks Wyoming on port 10300: enter tcp://<unraid-ip>:10300. It gives no timestamps, so lines are timed in 15-second blocks.
  4. Use the Unraid server's LAN IP, not localhost. Inside this container, localhost means the container itself.

Setting up the app registration

  1. In the Entra admin centre, open App registrations → New registration. Name it "Radio Logger", choose Accounts in this organizational directory only, and add the redirect URI above as a Web platform.
  2. Copy the Application (client) ID and Directory (tenant) ID from the Overview page into this form.
  3. Under Certificates & secrets, create a client secret and paste its Value here.
  4. Under App roles, create two roles for Users/Groups: value Admin and value Viewer.
  5. In Enterprise applications → Radio Logger → Users and groups, assign people or groups to those roles. To limit sign-in to assigned users only, set Properties → Assignment required to Yes.
  6. Using groups instead? Under Token configuration, add a groups claim (choose "Groups assigned to the application") and paste the admin group's object ID above.
